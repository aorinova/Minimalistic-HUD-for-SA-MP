# Minimalistic HUD for SA-MP
## Этот репозиторий является исключительно архивом работы 2021 года
### Минималистичный HUD для SA-MP (GTA SA). За основу был взят developezHUD. 

- Для установки прочтите инструкцию.
- Настройки: /hud_settings, изменить позицию HUD'а: /hud_pos.
- Требования: CLEO 4.3, SAMPFUNCS 5.3.3 или выше, SA-MP 0.3.7 - R1 (ну или R2), MoonLoader v.027.0 или выше.
- HUD имеет адаптацию под ныне несуществующий Fruit Project (он же Pears Project, Sampik).
- Скриншоты: https://imgur.com/a/MQoOESD
- Авторы: #Northn, developez, и crybaby как создатели оригинального developezHUD, Aorinova.
